# iPhone 18 Pro Photography Master — Unified App

整合 Photographer-V2 與 Photo-Adjustment。

## Architecture
- Scene：拍攝入口
- Capture：現場 Camera controls
- Photographic Style：可於拍攝或後製設定的視覺方向
- Recipe：完整後製方案
- Adjustment：單項後製控制
- Workflow：Scene → Capture → Style → Edit

## Deploy
將整個資料夾內容放到 GitHub Pages root；不要刪除 `data/`、`examples/` 或 `samples/`。
