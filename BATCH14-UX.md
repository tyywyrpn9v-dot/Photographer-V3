# Batch 14 — Content & UX refinement

## Changes
- Scene data no longer contains scene-specific Photographic Style, Histogram, Format or Aspect Ratio rows.
- Histogram and Format/Aspect are general controls documented only in the General Guide.
- Every scene now has a concise description, suitable situations and avoid notes.
- Scene detail presents Description → Suitable → Avoid before Must / Options.
- Must and Options use the same three-column table: Parameter / Setting / Reason.
- Photos Style is represented only as a 0–100 intensity control on edit pages; Camera Photographic Style remains a separate capture concept and is not embedded in scenes.
- User-requested scene names are preserved, including Car Trial and Marco.
- Existing recipe grouping labels (original vs Japanese A/B/C) remain absent from UI.
